# Microdent Implant System — Sitio web

Catálogo digital B2B (sin ecommerce) con localizador de asesores comerciales por WhatsApp.

- Stack: Next.js 16 (App Router, Cache Components) · React 19 · TypeScript 5.9 · Tailwind CSS 4 · componentes estilo shadcn/ui (Radix) · nuqs · Sanity CMS (Fase 3).
- Documentación: [`docs/fase-1-arquitectura-y-diseno.md`](docs/fase-1-arquitectura-y-diseno.md) y [`docs/fase-2-prototipo.md`](docs/fase-2-prototipo.md).

```bash
npm install
npm run dev
npm test
```
